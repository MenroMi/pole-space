# Image Focal Point Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let an admin pick a focal point on a move image so the right part stays visible when the image is cropped on cards, the detail hero, and related-move thumbnails.

**Architecture:** Store two floats `focalX`/`focalY` (0..1) on `Move`, default `0.5` (center = today's behavior). Render with CSS `object-position` layered over the existing `object-cover` everywhere the image is cropped — no Cloudinary transforms, one source URL as today. The admin sets the point by dragging a marker over the upload preview in `MoveModal`.

**Tech Stack:** Next.js (App Router, RSC), Prisma 7.7.0, Postgres (Neon), react-hook-form + Zod, next/image, Vitest.

- [ ] **Step 3: Write the implementation**

Create `src/features/moves/lib/focal.ts`:

```ts
const clamp01 = (n: number): number => Math.min(1, Math.max(0, n));

/**
 * Convert a focal point (fractions in [0,1]) to a CSS `object-position`
 * value. Null/undefined or out-of-range inputs fall back to / clamp toward
 * center (0.5).
 */
export function focalToObjectPosition(x?: number | null, y?: number | null): string {
  const fx = clamp01(typeof x === 'number' && Number.isFinite(x) ? x : 0.5);
  const fy = clamp01(typeof y === 'number' && Number.isFinite(y) ? y : 0.5);
  return `${Math.round(fx * 100)}% ${Math.round(fy * 100)}%`;
}
```

'use client';
import { ImageOff } from 'lucide-react';
import Image from 'next/image';
import { useState } from 'react';

import { focalToObjectPosition } from '@/features/moves/lib/focal';

interface MoveCardImageProps {
  src: string;
  alt: string;
  focalX?: number;
  focalY?: number;
}

// YouTube returns a 120x90 "Unavailable" thumbnail (HTTP 200) for IDs that
// don't exist — we can't use onError. Instead we check the loaded image's
// naturalWidth: real hqdefault is 480px wide, placeholder is 120px.
const YOUTUBE_PLACEHOLDER_MAX_WIDTH = 120;

export default function MoveCardImage({ src, alt, focalX, focalY }: MoveCardImageProps) {
  const [failed, setFailed] = useState(false);

  if (failed) {
    return <ImageOff className="h-10 w-10 text-muted-foreground" aria-hidden="true" />;
  }

  return (
    <Image
      src={src}
      alt={alt}
      fill
      style={{ objectPosition: focalToObjectPosition(focalX, focalY) }}
      className="object-cover transition-transform duration-700 group-hover:scale-105"
      onLoad={(e) => {
        if (e.currentTarget.naturalWidth <= YOUTUBE_PLACEHOLDER_MAX_WIDTH) {
          setFailed(true);
        }
      }}
      onError={() => setFailed(true)}
    />
  );
}
